# Support

## How to get help

- **Getting started friction:** use the **Getting started problem** issue form
- **Bugs and questions:** open a [GitHub Issue](https://github.com/ameenmari/agentprodready/issues)
- **Documentation / DX feedback:** Issues are welcome; see [labels](docs/community/labels.md)
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) — do **not** file a public issue for exploitable bugs
- **Discussions:** enable manually in GitHub Settings when ready (see [manual-actions](docs/implementation/manual-actions/github-repository-metadata.md))

## Expectations

- There is **no support SLA** and no paid support channel today.
- Response time depends on maintainer availability (single maintainer: [ameenmari](https://github.com/ameenmari)).
- Best-effort answers; pull requests that improve docs or reproduction cases are appreciated.
- This is not foundation-scale governance.

## Before opening an issue

1. Try [Getting Started](docs/guides/getting-started.md) or `npm create agentprodready@latest` (when published) / [`examples/hello-agent`](examples/hello-agent).
2. Confirm Node.js **`>=22 <25`** and ESM usage.
3. Include package versions, minimal reproduction, and whether you used `reference()`, `openai()`, or `openaiCompatible()`.
