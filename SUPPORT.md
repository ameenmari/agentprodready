# Support

## How to get help

- **Bugs and questions:** open a [GitHub Issue](https://github.com/ameenmari/agentprodready/issues)
- **Documentation / DX feedback:** Issues are welcome; label suggestions help
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) — do **not** file a public issue for exploitable bugs

## Expectations

- There is **no support SLA** and no paid support channel today.
- Response time depends on maintainer availability (single maintainer: [ameenmari](https://github.com/ameenmari)).
- Best-effort answers; pull requests that improve docs or reproduction cases are appreciated.

## Before opening an issue

1. Try the [Getting Started](docs/guides/getting-started.md) path with `@agentprodready/agent-framework`.
2. Confirm Node.js **24** and ESM usage.
3. Include package versions, minimal reproduction, and whether you used `reference()` or `openai()`.
