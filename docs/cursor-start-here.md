Do not begin implementation immediately.

First:

1. Inspect the repository.
2. Confirm the required documents exist.
3. Identify missing or contradictory architecture.
4. Create the blueprint implementation plan.

The blueprints and accepted ADRs are authoritative.

Existing code must not override approved architecture.
