# streaming-agent

## What problem does this solve?

Focused library `stream()` demo (not HTTP SSE).

## How do I run it?

```bash
npm install
npm start
```

## Env variables

None (`reference()`).

## Expected output

Streamed text that ends as `Hello` (deterministic reference).

## Is it production-safe?

No — local demo. For services see [embed-agent-deployment.md](../../docs/guides/embed-agent-deployment.md).
